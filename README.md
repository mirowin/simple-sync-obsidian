# Simple Encrypted Sync для Obsidian

Плагин синхронизирует одно хранилище Obsidian между компьютером и Android-телефоном через ваш VPS. В комплект входит веб-просмотрщик Markdown с доступом только для чтения.

## Что уже работает

- автоматическая синхронизация каждые 30 секунд и через 2 секунды после изменения файла;
- заметки, изображения, PDF и любые другие файлы хранилища;
- сквозное шифрование AES-256-GCM: сервер не получает ключ, имена файлов или открытое содержимое основной копии;
- проверка целостности SHA-256;
- безопасное разрешение конфликтов через отдельную `conflict-...` копию;
- подключение второго устройства одним секретным кодом;
- отдельная веб-копия только выбранных файлов;
- Markdown, Obsidian `[[wiki links]]`, вложения `![[...]]`, поиск, светлая и тёмная темы, мобильная вёрстка;
- публичные папки, закрытые исключения и индивидуальные ссылки, которые можно отозвать.

Служебная папка `.obsidian` не синхронизируется. Это специально: настройки интерфейса и наборы плагинов на телефоне и компьютере могут отличаться.

## 1. Развёртывание сервера на VPS

Нужен домен или поддомен, A-запись которого указывает на IP вашего VPS. На сервере должны быть установлены Docker и Docker Compose, а порты 80 и 443 должны быть открыты.

### Автоматическая установка

Репозиторий приватный, поэтому сначала добавьте SSH-ключ VPS в GitHub как deploy key с правом чтения. После этого на чистом Debian или Ubuntu достаточно выполнить:

```bash
git clone git@github.com:mirowin/simple-sync-obsidian.git
cd simple-sync-obsidian
sudo ./scripts/install-vps.sh --domain sync.example.com
```

Если на VPS уже настроен GitHub CLI, вместо SSH можно использовать `gh repo clone mirowin/simple-sync-obsidian`.

Скрипт:

- установит Docker Engine и Docker Compose из официального репозитория, если их ещё нет;
- скопирует сервер в `/opt/simple-sync-obsidian`;
- настроит Caddy и автоматический HTTPS;
- откроет порты 80/443 в UFW, если UFW уже активен;
- создаст `simple-sync-obsidian.service`;
- включит автозапуск после перезагрузки VPS;
- поднимет контейнеры и проверит `/health`.

Скрипт идемпотентный: его можно запускать повторно после обновления исходников.

Полезные команды:

```bash
sudo systemctl status simple-sync-obsidian
sudo systemctl restart simple-sync-obsidian
sudo journalctl -u simple-sync-obsidian -f
```

### Ручная установка

1. Скопируйте на VPS серверный архив и распакуйте его.
2. В каталоге создайте `.env` по примеру `.env.example`:

   ```env
   SYNC_DOMAIN=sync.example.com
   ```

3. Запустите:

   ```bash
   docker compose up -d --build
   ```

4. Проверьте:

   ```bash
   curl https://sync.example.com/health
   ```

   Ожидаемый ответ: `{"status":"ok"}`.

Caddy автоматически получает и обновляет HTTPS-сертификат. Данные сохраняются в Docker volume `sync_data` и не исчезают при обновлении контейнера.

### Резервная копия серверных данных

```bash
docker run --rm -v simple-encrypted-sync_sync_data:/data -v "$PWD":/backup alpine \
  tar czf /backup/simple-sync-backup.tar.gz -C /data .
```

Имя volume можно проверить командой `docker volume ls`.

## 2. Установка плагина на компьютер

1. Закройте Obsidian.
2. Внутри нужного хранилища создайте каталог:

   `.obsidian/plugins/simple-encrypted-sync`

3. Распакуйте туда `manifest.json`, `main.js` и `styles.css` из плагин-архива.
4. Откройте Obsidian → **Настройки → Сторонние плагины**.
5. Отключите безопасный режим, если он включён, и активируйте **Simple Encrypted Sync**.
6. Откройте настройки плагина, укажите `https://sync.example.com` и нажмите **Создать**.
7. Скопируйте появившийся код подключения и сохраните его в менеджере паролей.

## 3. Установка на Android

1. Полностью закройте Obsidian.
2. В файловом менеджере включите отображение скрытых файлов.
3. В каталоге того хранилища, которое открывает Obsidian, создайте:

   `.obsidian/plugins/simple-encrypted-sync`

4. Распакуйте туда те же три файла: `manifest.json`, `main.js`, `styles.css`.
5. Запустите Obsidian → **Настройки → Сторонние плагины** и включите плагин.
6. В настройках плагина вставьте код с компьютера в поле **Код подключения** и нажмите **Подключить**.

Первое объединение может создать conflict-копию, если в одноимённых заметках на устройствах уже разное содержимое. Ничего не удаляется без сохранения изменённой версии.

## 4. Веб-просмотрщик и права

Основное хранилище остаётся зашифрованным. Для просмотра сервер получает отдельный открытый снимок только тех путей, которые разрешены правилами публикации.

Правило записывается одной строкой:

```text
public | Публичное
private | Публичное/Черновики
link | Семья | ключ-для-анны
link | Семья | другой-ключ-для-ивана
```

- `public` — любой посетитель может читать папку или файл;
- `link` — доступ есть только по адресу с `?key=секрет`;
- `private` — закрывает путь, даже если родительская папка открыта;
- более длинный, то есть более точный путь имеет приоритет;
- при одинаковом пути `private` имеет приоритет;
- несколько строк `link` для одного пути создают отдельный ключ каждому человеку.

Пример ссылки для Анны:

```text
https://sync.example.com/view/ИД-ХРАНИЛИЩА/?key=ключ-для-анны
```

Чтобы отозвать доступ только у Анны, удалите её строку `link` и нажмите **Опубликовать**. Остальные ссылки продолжат работать.

По умолчанию публикуется только папка `Публичное`. Чтобы открыть весь vault, укажите `public |` без пути. Это действие нужно использовать осторожно.

На втором устройстве публикация по умолчанию выключена, чтобы телефон случайно не перезаписал правила, настроенные на компьютере.

## Ограничения MVP

- нет истории версий на сервере — есть только текущая версия и локальные conflict-копии;
- выдача доступа основана на индивидуальных секретных ссылках, без учётных записей и e-mail;
- серверные бинарные блоки пока не удаляются автоматически после удаления заметок;
- публикация больших каталогов формирует один снимок, поэтому для медиатеки на десятки гигабайт понадобится потоковая публикация.

Для личного Obsidian и небольшой публичной базы знаний текущая схема рассчитана на простую установку и предсказуемое восстановление данных.
